# Workflow: Frontend Review UI

Use this workflow when changing the frontend in `starter_app/frontend/`.

## Steps

1. Read `docs/04_frontend_options.md`.
2. Run the starter app locally.
3. Exercise text input and demo extraction.
4. Make the UI change.
5. Verify that the page still shows:
   - raw text;
   - product code;
   - description;
   - confidence;
   - alternatives;
   - final JSON.
6. Confirm no Gemini API key is referenced in frontend files.

## UI Style

This is an operational review tool. Keep it compact, readable, and suitable for repeated back-office use.
